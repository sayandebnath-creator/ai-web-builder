# 🌐 AI-Powered Web Page Builder

AI-powered web editor built on **GrapesJS** with a **Python backend**.  
Enables drag-and-drop website creation with AI-assisted generation and editing.

> ⚠️ MVP for *AI Integration in GrapesJS Website Builder* 

---

## 🚀 Features

- 🤖 AI website generation & modification  
- 🖼️ Drag-and-drop visual builder  
- 🐍 Lightweight Python backend  
- 🌐 Multi-language support  
- 🎨 Clean UI  

---

## ⚙️ Setup

```bash
git clone https://github.com/sayandebnath-creator/ai-web-builder.git
cd ai-web-builder
pip install -r requirements.txt
mv .env.example .env
# Add API keys (OpenAI, Anthropic)
python app.py
